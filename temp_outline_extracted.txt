Trang 1 — Abstract + Executive Summary (0.5 trang)
Trong quá trình phát triển thuốc, khoảng 30% số thuốc thử nghiệm bị loại bỏ do không phát hiện sớm độc tính, góp phần đẩy chi phí phát triển lên hơn 2,6 tỷ USD cho mỗi loại thuốc mới. Nền tảng này vận hành dựa trên mô hình học máy tập hợp hai đầu (dual-head ensemble GNN/Transformer) kết hợp công cụ GNNExplainer nhằm cung cấp các đánh giá minh bạch về cấu trúc phân tử. ToxAgent đạt hiệu suất dự đoán xuất sắc với chỉ số joint_auc_beta3 tốt nhất là 0,8467. 3c. SMILES Input Normalization — NLP layer
extract_smiles_from_text(): regex token extraction → heuristic filter (_looks_like_smiles) → RDKit validation → canonical form
Cho phép user gõ câu tự nhiên như "phân tích CCO có độc không?" — pipeline tự extract CCO
Xử lý false positive: loại bỏ lowercase words, require ≥2 uppercase atoms hoặc chemistry symbols
3d. MolRAG Module — Chi tiết kỹ thuật
Retrieves structural analogs từ Firestore (sentence-transformers embedding)
retrieve_knowledge_context(): knowledge_hits (mechanism DB) + literature_hits (PubMed)
Confidence formula: min(0.95, 0.4 + similarity×0.4 + n_analogs×0.05 + n_knowledge×0.015 + n_lit×0.01)
Deterministic reasoning: majority vote từ analog labels, override nếu high-risk mechanism detected
Strategy flags: sim_cot (similarity chain-of-thought)
Fallback: nếu không có analog → MolRAG acts as supporting context, keeps baseline
3e. Model Architecture — Dual-Head (giữ nguyên từ outline trước)
Trang 4–5 — Agent Deep Dives (1.5 trang)
4a. ScreeningAgent
Gọi /analyze endpoint với configurable params: clinical_threshold, mechanism_threshold, inference_backend, binary_tox_model, tox_type_model
Parallel: ScreeningAgent + ResearcherAgent chạy đồng thời qua ThreadPoolExecutor(max_workers=2)
Trả về: screening_result + explanation_raw (GNNExplainer output)
4b. ResearcherAgent
Fetch PubChem CID → compound metadata
Fetch PubMed abstracts với SMILES-derived query
Output enriches WriterAgent context
4c. WriterAgent — build_final_report()
Input: smiles_input + screening_result + research_result + explanation_raw + language
Output schema: report_metadata, executive_summary, risk_level, sections{clinical_toxicity, mechanism_toxicity}
Bilingual support: Vietnamese / English toggle
4d. ReportChatAgent ← THIẾU HOÀN TOÀN Ở OUTLINE TRƯỚC
35KB agent — lớn nhất trong codebase
Interactive Q&A sau khi report được tạo xong
Cho phép chemist hỏi "tại sao model dự đoán NR-AR positive?", "có analog nào safe hơn không?"
Context-aware: có access vào full screening_result, research_result, MolRAG context
Đây là feature differentiator lớn nhất so với tất cả competitive tools
4e. EvidenceQAAgent ← THIẾU HOÀN TOÀN Ở OUTLINE TRƯỚC
Grounding agent: kiểm tra lại evidence citations trong report
Phân biệt claims có literature support vs. model-only claims
Tăng scientific credibility của output report
