# Response R06

**I would not rely on these negative calls to clear bortezomib.** ToxPred itself marks the compound as having *limited applicability* because it contains boron, and it provides no similarity-domain result. Its hERG score (0.217, below the 0.413 cutoff) and twelve inactive Tox21 calls are model classifications, not measurements or estimates of clinical risk. We also lack validation showing how well those scores perform for boronic acids.

There is a concrete warning sign in the Tox21 output: ToxPred calls **SR-p53 inactive** (0.183 versus a 0.350 cutoff), while published Tox21 screening reports bortezomib as p53-active, with an EC₅₀ of about **0.015 µM**. Proteasome inhibition can stabilize and activate p53, so that assay result does not by itself establish DNA damage; it does show that the blanket negative panel is unreliable for this compound. [Tox21 screening study](https://molpharm.aspetjournals.org/article/S0026-895X%2826%2900016-7/fulltext), [mechanistic study](https://pubmed.ncbi.nlm.nih.gov/14612532/).

For hERG, the prediction is a weak screening signal, not clearance. The [VELCADE label](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=1521d321-e724-4ffc-adad-34bf4f44fac7) reports isolated QT prolongation cases but says causality is unestablished; those cases do **not** demonstrate hERG block. If this result will drive a decision, use a measured hERG concentration–response assay and assess it against unbound exposure, as described in [ICH E14/S7B guidance](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/e14-and-s7b-clinical-and-nonclinical-evaluation-qtqtc-interval-prolongation-and-proarrhythmic). I would also check ToxPred’s bortezomib identity, training label, and boron coverage before using its Tox21 output again.
