# Response R01

**Short answer: yes, hERG liability is a real and well-characterised concern for sotalol — the ToxPred output is wrong here, and this is a useful false-negative case study for the team.**

## The prediction

ToxPred returns `non_blocker` (p = 0.31, threshold 0.41) and no Tox21 flags. Applicability domain is reported "ok", but note the caveat in the JSON itself: the chemical guard only checks element composition and explicitly says it "cannot confirm distributional similarity beyond element composition." `similarity_domain` is `null` — so there is no real domain check behind that "ok".

## Why it's wrong

Sotalol's *mechanism of action* as a class III antiarrhythmic is IKr (hERG/KCNH2) blockade — it's a non-selective β-blocker plus a potassium channel blocker. Blocking hERG is what it's for. Specifically:

- It is one of the reference positive controls in the CiPA initiative's compound set and is routinely used as a positive control in hERG patch-clamp and QT studies.
- It carries a boxed warning for QT prolongation and torsades de pointes; dosing requires baseline/on-treatment ECG monitoring and renal dose adjustment (renally cleared, so accumulation drives QT risk).
- hERG IC50 is in the high-micromolar range (roughly hundreds of µM in patch clamp), so on a raw potency basis it's a *weak* blocker — but it's dosed at high plasma concentrations (tens of µM), so the safety margin is narrow. That combination is the whole point.

That last point is probably why the model missed it. Sotalol is small (MW 272), hydrophilic (logP ~0.24), and lacks the canonical hERG pharmacophore — a basic centre plus bulky lipophilic/aromatic domains. It does have the secondary amine, but the methanesulfonanilide head group is polar and the molecule is overall unlike the classic cationic amphiphile blockers (dofetilide, astemizole, terfenadine) that dominate hERG training sets. The model is essentially reading physicochemistry and concluding "too polar to block hERG," which is right about intrinsic potency and wrong about clinical risk.

## What I'd tell the project team

1. **Don't use ToxPred to triage sotalol or any methanesulfonanilide.** The chemotype (sotalol, dofetilide, ibutilide, E-4031) is a known hERG-blocking series that structure-based classifiers tend to under-call. Treat a `non_blocker` call on this scaffold as uninformative.

2. **Sotalol remains a good comparator — but be clear what it's a comparator *for*.** It's a positive control for QT prolongation in vivo and a CiPA reference compound. It is a poor choice if you want a potency-matched hERG positive control in patch clamp, because the IC50 is so high; use dofetilide or E-4031 for that.

3. **This is a margin problem, not a potency problem.** If the programme's internal decision rule is "hERG IC50 > X µM = clear," sotalol would pass and is nonetheless a torsadogenic drug. Worth using it to pressure-test the safety-margin criterion — the team should be computing IC50 / free Cmax (or an exposure-adjusted margin), not IC50 alone. A ~30x or narrower margin is typically where concern starts.

4. **On the Tox21 panel:** the all-negative result is unremarkable and I'd read it as roughly consistent with what's known — sotalol's liability is cardiac electrophysiology, which Tox21 doesn't interrogate. Absence of nuclear-receptor/stress-response flags says nothing about proarrhythmia. Don't let a clean Tox21 card read as a clean safety profile.

5. **Process point.** If the team is relying on this predictor for go/no-go, I'd push for (a) a real applicability-domain check with nearest-neighbour Tanimoto similarity rather than the element-composition rule, and (b) a curated set of known blockers — including the sulfonanilides and other polar blockers — run as a standing regression test. Sotalol failing silently suggests the validation set is skewed toward lipophilic amines.

Happy to pull the CiPA reference values and put together a small benchmark set of known blockers to run through ToxPred if that would be useful for the validation question.
