# Scientific investigation backlog

Executes [`RETHINK_TOXAGENT_AGENTIC_RESEARCH_EVALUATION_VI.md`](../RETHINK_TOXAGENT_AGENTIC_RESEARCH_EVALUATION_VI.md)
(read at commit `ad66022`, 2026-09-25). Branch: `feat/scientific-investigation`.

## Target state

ToxAgent stops being "a chat turn that calls the predictor" and becomes a
**case-based investigation copilot**:

- the unit of work is a durable `ScientificCase` (decision question, competing
  hypotheses, evidence ledger for/against, uncertainty ledger, action log,
  conditional conclusion) that survives across turns and can be replayed;
- the run's product is a typed `DecisionDossier` compiled by the server from
  that case; chat, report and UI are views of it;
- the three explanation layers (model attribution / scientific evidence /
  agent decision) are separate, and each carries its measured reliability;
- investigation methods ship as versioned, hash-pinned **skills** the agent
  discovers from metadata and loads on demand through closed MCP tools, not as
  new code paths or ever-longer prompts;
- claims about capability come from a scorecard that never merges axes:
  `external-native` benchmarks, `published-data-transfer` studies, and
  `product-regression` (TAB-Suite).

## Decisions taken for this execution (2026-09-25, product owner)

1. **"SME" arms are platforms, not graders.** ChatGPT, Gemini and Claude answer
   the same investigation cases as ToxAgent so outputs can be compared. They do
   not score anything.
2. **Quality grading is deferred to a chemistry lab.** Until then the hard
   requirement is *complete logging*: every prompt, raw output, resolved model
   id, timing, cost, ToxAgent trace and case state, plus a blinded grading
   packet whose unblinding key is kept separate.
3. **Order.** The RETHINK doc is ambiguous between §4.11 (case memory only after
   the skill pilot shows signal) and §6 (P1 and P2 in parallel). This execution
   builds the case substrate and the skill catalog behind default-off flags in
   the same pass, and leaves the *release* decision to the paired measurements
   (§5.5), which keeps both readings honest: nothing reaches the default product
   until measured.
